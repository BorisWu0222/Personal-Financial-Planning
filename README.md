# 📈 個人理財與退休試算工具 (Personal Financial Planning)

專為準備求職、談薪水或面臨職涯抉擇的社會新鮮人與專業人士設計的「動態財務模型」。透過視覺化的數據，幫助你具象化不同起薪、職涯發展與重大生活選擇（如買房或租房）對長期資產累積的真實影響。

## 💡 為什麼需要這個工具？

在拿到 Offer 準備談薪水，或是猶豫要選擇哪一條職涯路徑時，我們很難憑空想像「現在的月薪」在十年、二十年後會變成什麼樣的生活水準。

本工具摒棄了不切實際的「單利計算」，導入了**實質利率折現**、**通膨調整**以及**各國真實稅率**，讓你能用顧問級的邏輯，為自己做一場嚴謹的財務壓力測試。用數據輔助決策，讓你對未來的選擇更有底氣！

## ✨ 核心功能特色

* 📊 **職涯薪資情境模擬**：內建多種預設薪資成長曲線（如科技工程、金融顧問、行政服務等），並支援客製化分段調薪幅度，輕鬆比較不同 Offer 的長期價值。
* 🏠 **買房 vs. 租房比較模型**：輸入房屋總價、頭期款、房貸利率與租金漲幅，系統將同步繪製兩者的資產累積曲線，直觀比較哪種居住決策更具財務效率。
* 🧮 **真實稅務與通膨還原**：內建台灣及多國最新所得稅級距（含標準/免稅額計算），並扣除通膨影響下的日常開銷，還原最真實的「稅後可支配現金流」。
* 🎯 **退休目標回測**：設定預期退休年齡與退休替代率，系統會自動反推所需的「安全退休金水位」，並抓出最早可退休的精確年齡。

## 🛠️ 如何使用？

這是一個純前端的網頁應用程式（SPA），不需安裝任何軟體。

1. **直接網頁操作**：點擊上方的 Live Demo 連結進入系統。
2. **設定基準參數**：在左側欄位輸入你的年齡、預期壽命與緊急預備金目標。
3. **切換模式**：
   * `現實模式`：適合已經有具體薪資數字，想推演未來資產軌跡的人。
   * `目標模式`：給定一個理想退休年齡，系統會反推「你需要拿多少起薪、搭配哪種職涯情境」才能達成目標。
4. **動態圖表與現金流報表**：每次調整參數，右側的 Chart.js 圖表與逐年現金流報表都會即時更新。
